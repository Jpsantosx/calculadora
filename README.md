# Calculadora em Python

Calculadora de terminal com as quatro operações matemáticas básicas e menu interativo.

## Funcionalidades

- Adição, subtração, multiplicação e divisão
- Validação das opções escolhidas
- Execução contínua até o usuário sair

## Tecnologias

![Python](https://img.shields.io/badge/Python-20232A?style=flat-square)

## Como executar

Execute:

```bash
python calculadora.py
```
